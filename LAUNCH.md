# Запуск и публикация

Откройте `index.html` двойным щелчком или через VS Code Live Server. Установка пакетов и сборка не нужны. Все изображения находятся в проекте; интернет для игры не требуется.

- HOME открывает стартовую страницу.
- GAME 1 / GAME 2 переключают игры без перезагрузки и сохраняют текущий раунд.
- FULL SCREEN включает полноэкранный режим; выход — той же кнопкой или Esc.
- Game 1: SPIN → составьте предложение → SHOW ANSWER. Доступны 14 занятий.
- Game 2: SPIN WHO + ACTIVITY выбирает персонажа и занятие, SPIN HOW OFTEN — частотность. Готовый вопрос открывается кнопкой SHOW QUESTION, полный ответ — SHOW ANSWER в нижней панели. Для нового вопроса снова нажмите SPIN WHO + ACTIVITY. Можно повторно вращать HOW OFTEN для того же вопроса.
- Управление мышью и клавиатурой: Tab, Enter / Space для кнопок.

Экран игры масштабируется целиком с сохранением пропорций 16:9. Навигация занимает отдельную полосу над игрой. На экранах другой формы остаются свободные поля; прокрутки нет.

В Game 2 убраны подписи на колесе занятий и под ним: плашки результатов под колёсами убраны, колесо занятий увеличено примерно на 30%. Get up late и go swimming заменены на read a book и ride a bike. В WHO добавлено I, персонажи показаны крупными портретами. Сохранены две кнопки вращения. Вопрос и ответ скрыты до нажатия SHOW QUESTION / SHOW ANSWER; новый раунд снова скрывает оба текста, повторное вращение HOW OFTEN скрывает ответ.

## GitHub Pages

1. Загрузите `index.html`, папки `css`, `js`, `games`, `assets` и файл `.nojekyll` в корень репозитория, сохранив регистр и структуру путей.
2. В настройках репозитория выберите Pages → Deploy from a branch → вашу ветку и `/ (root)` → Save.
3. Откройте опубликованный адрес. Используются относительные пути, поддерживается адрес вида `https://USER.github.io/REPOSITORY/`.

Папка `tests` содержит проверки и снимки экранов; для работы сайта она не нужна. Публикация автоматически не выполнялась.

## Повторная проверка

`tests/check.cjs` проверяет неизменность исходного дизайна автомата, 630 предложений Game 1 и 360 сочетаний Game 2, навигацию, оба разрешения, категории, геометрию секторов, механику двух кнопок, отсутствие прокрутки и внешних запросов, запуск через file:// и HTTP из подпапки.

Нужны Node.js и отдельно установленный совместимый Playwright. Укажите путь к пакету в `PLAYWRIGHT_MODULE` и при необходимости путь к Chrome в `CHROME_PATH`, затем выполните `node tests/check.cjs` из корня. Инструменты нужны только для проверки и не подключаются к игре.
